## Overview

Benri Tools is a browser-first collection of practical utilities built with HTML-based workflows. Rather than scattering small web helpers across separate projects, it provides one central interface for accessing productivity-oriented tools directly from a browser.

The suite is designed to remain easy to set up and suitable for static-site deployment. You can run it locally or place it on a web server, giving you a compact utility hub without the overhead of a larger application stack.

## Getting Started

1. Clone the repository or obtain a copy of its source files.
2. Put the project in a web server's document root, or serve it with a local static server.
3. Open the primary HTML entry file in your browser.

For example:

- Clone the project: `git clone https://github.com/scottlucasrrs7889/benri-tools-browser-hub.git
- Run locally: start a static server in the project directory and open the site in your browser

## Using the Suite

Begin at the main page, then select a utility from the hub. Most sessions follow this sequence:

1. Open the site
2. Choose a tool
3. Provide the requested content or values
4. Inspect the output in the browser

## Frequently Asked Questions

**What is the update process for Benri Tools?**  
Install the newest project files in place of the current ones and refresh the site in your browser.

**Is local usage supported?**  
Yes. Benri Tools can run locally or from a hosted static deployment.

**Where can I modify the configuration?**  
Review the HTML files and shared static assets that define the interface and the behavior of the utilities.

**How should I troubleshoot a tool that fails to load?**  
Verify that every project file was copied, check that the browser can reach the required assets, and confirm that you opened the intended entry page.

**Does Benri Tools need a backend service?**  
No. The basic setup described here is a browser-based static application and does not require a backend.
